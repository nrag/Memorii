# Blocker Remediation V5

This normative delta closes `VCC-DREV-001D`, `VCC-DREV-001E`, and
`VCC-DREV-008B` without production-code or repository-test changes.

The callback attack proof uses an externally owned arm/check/disarm probe. Each
actual callback invocation consumes a unique ordinal plus immutable event
identity; writer event-list state is not used as the observer. Reorder preserves
bytes and count while changing observed order. Omission and extra invocation
change observed count by exactly one. Independent matrices run for mixed set
and mixed frozenset wrapper subjects.

The v6 owner graph is read-only and source-bound. Twelve production files are
frozen by SHA-256. Five real event triggers, four composition roots, and the
evidence-only capture harness are classified separately. Calls are admitted
only when exact caller, call expression, required keywords, target symbol, and
receiver/import/parameter/field binding agree. Each static row segment is
directed and connected; dynamic branch bridges remain explicit implementation
proofs rather than invented edges.

Mutations keep the oracle fixed. Ledger attacks cover wrong same-name targets,
constructor reversal, disconnected paths, capture-root substitution, missing
authority keywords, and R08 durable relabeling. Shadow-source attacks cover a
wrong receiver, substituted nonce authority, and direct or aliased durable
sinks in the arena. Hash checks are disabled only for shadow attacks so failure
must come from the semantic predicate. The validator verifies that ledger and
oracle bytes remain unchanged.
