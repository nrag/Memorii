# Observation Ledger Entrypoint Verification Matrix

Status: implementation-proof design. It names future tests and signals; it does
not claim any runtime route is implemented or activated.

Every integration case uses the normal production composition path. A test must
fail when the named argument or authority edge is removed, substituted, or
bypassed. A direct helper, fabricated registry, fixture-only store, or
replacement commit owner is insufficient evidence.

| Entry point and level | Required composed authority | Scenario and observable signal | Removal/substitution signal |
| --- | --- | --- | --- |
| Independent profile compiler, package-level | Raw role package, whole-file decoder-source manifest, independently authored compiler; no runtime registry/models/callbacks | Compile the finite inventory and compare publication/registry/vector inputs to independently expected bytes | Importing `ingestion_contracts.py`, generated constants, reflection, a callback, a source-region selector, or an unpinned native validator/encoder dependency causes compiler isolation failure |
| `ProviderMemoryService` -> `BuiltInLocalHostSemanticIngestionCapability.build_semantic_ingestion_runtime`, integration | One verified immutable registry instance passed to writer admission, `SemanticIngestionAtomicStore`, replay, and observation service | Instrument identity at all four owners during normal service construction; all see the same object and matching publication pins | Omit or replace any constructor argument, or build a private registry in one owner; ledger mode is unavailable before write/read and identity assertion fails |
| Same provider composition with JSONL retained history, integration | Shared registry status admission and exact embedded historical binding | Reject activated writes under `replay_only` or `retired` before durable write; internal reload selects the original decoder for an exact retained binding; public registered read rejects non-public status; same-coordinate status/source-snapshot/decoder substitution prevents service publication | Record store access and decoder selection. Removing status admission or substituting a current entry must fail before durable write or body decode, never return successful fallback |
| `ProviderMemoryService.sync_event` -> native V3 group CAS, JSONL integration | Verified registry, writer admission, retained policy bundle, atomic-store group commit owner | Accepted fact writes one group primary with graph delta/event batch, temporal/trust publications, immutable receipt/evidence, aggregate/checkpoint, ledger entry/head; restart reload preserves exact closure | Remove registry/admission/bundle/receipt argument or replace `commit_or_reload_bootstrap_graph_group_v3`; no write succeeds, or byte-for-byte closure assertion fails |
| Same `sync_event` route, JSONL integration | Native source terminal assembler and terminal publication owner | Group plus source finalization writes ordered group/source audit entries in their actual owners; a zero-operation source writes only its allowed source closure | Drop source intent/terminal authority or route through generic terminal helper; manifest/result/entry membership assertion fails; zero-operation source must not manufacture group effects |
| Activation, crash, CAS, and restart integration | `SemanticWriterAdmissionStore`, governed policy, `MemoryPlaneService` full write snapshot guard, atomic activation owner | Inject crash before/after activation batch, stale full-write token, and process restart; observe either old admission/no head or new admission/genesis head, never a mixed epoch | Remove admission/expected-write-revision/atomic owner argument; stale activation succeeds or mixed durable state appears, which fails exact JSONL reopen inspection |
| Competing JSONL process integration | Existing atomic group/source commit owners and backend CAS | Two processes attempt accepted group/source commits at one guarded head; exactly one owns each coordinate, loser retries/reloads, restart replay sees contiguous ledger | Replace owner with a test transaction or omit expected head; both winners, partial writes, or noncontiguous replay proves failure |
| `ObservationReplayService` configured checkpoint create/load, integration | Protected lifecycle/key configuration, verified registry, detached full snapshot, observation replay owner | Create checkpoint at a committed head, reopen, verify signature/preimage/lifecycle and tail replay | Omit/swap lifecycle, registry, key, or snapshot argument; checkpoint creation/load rejects before accepting a prefix; graph checkpoint substitute rejects |
| `ProviderMemoryService.observe_graph`, public API integration | Out-of-band authorizer, same verified registry, `MemoryPlaneService.read_write_snapshot`, `GraphObservationService` | Denied request produces canonical non-disclosing denial with zero store reads; allowed request returns both separately typed temporal and trust projection records with native generation/pointer coordinates | Remove authorizer/registry/snapshot argument or use caller principal; read spy observes unauthorized lookup, registry fallback, or merged projection shape and test fails |
| `ProviderMemoryService.observe_ingestion_time_attestations`, public API integration | Same authorizer/registry/snapshot path, attestation-specific request coordinates | Authorized result contains only typed source/group time attestations from one cohort; denial reads nothing | Substitute graph facade, omit request-coordinate binding, or read before authorization; cross-purpose records or read spy fail |
| Public observation page continuation, API plus JSONL restart integration | Retained snapshot token, signed cursor, current authorizer, fresh full write snapshot, protected page policy | First page records `snapshot_write_revision`; an intervening group, source, temporal-only, or trust-only publication makes continuation stale; restart/eviction is stale, never reconstructed | Remove write-revision comparison, cursor/request binding, page policy, or reauthorization; continuation emits a page, gap, overlap, or mixed projection coordinate and fails |

The native group/source tests must use real `ProviderMemoryService.sync_event`
and the configured JSONL backend. The checkpoint and observe tests must use the
same production composition root rather than constructing `GraphObservationService`,
`ObservationReplayService`, registry, or atomic store in isolation. Fault
injection may wrap backend calls, clock, or process lifecycle, but it may not
replace the admission, terminal, group-commit, replay, or observation owner.
