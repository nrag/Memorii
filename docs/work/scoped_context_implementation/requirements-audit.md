# Independent Implementation Obligation Audit

Coordinator reconstructed from approved contract prose before reading new code.
Traceability table supplements, rather than replaces, these acceptance boundaries.

1. Every public model forbids extras, invalid enums and blank identity; request
   duplicate refs/optional domain/UTC/structured reference mismatch fail closed.
2. Failure envelopes contain no request echo, receipt, revision, items or omissions;
   complete/partial and structured answered/no-match/abstained states are coherent.
3. Host provisions separate local read authority. Handles are unforgeable object
   identities and reusable until expiry/revoke; audit labels are not credentials.
   Grant construction validates exact rows, duplicate rows and all-null allowlists.
4. Authority resolves before data access and revalidates under its lock immediately
   before release; expiry equality and revoke/reprovision deny. No ingress service
   authority, remote trust scheme or persisted handles are introduced.
5. Exactly one cloned snapshot supplies every canonical catalog and result;
   repository snapshot decoder has no live-store escape hatch. Malformed owned
   payloads/backend faults are typed unavailable, unexpected bugs propagate.
6. Exact full namespace equality and finite null-scope IDs precede index/scoring.
   Runtime-visible committed records only, all six domains for mandatory refs.
7. Source closure includes canonical IDs, claim spans, link spans and anchor
   sources/evidence; decoded inner scope matches envelope. Missing required
   sources cannot leak via catalogs, counts or result text. No fabricated provenance.
8. Current mandatory/lexical claim truth uses ClaimStateQueryService; generic
   validity is half-open and never promotes expired/invalidated records. Structured
   historical readers retain eligible historical state until query-time filtering.
9. All mandatory IDs resolve or entire mandatory response fails. Optional work
   cannot begin after mandatory overflow/unresolved outcome.
10. BM25 reuses local tokenizer and stable channel/descending-score/ID order.
    No ranker quality claim and no configured remote analyzer dependency.
11. Structured runtime uses local one-shot guarded analysis: ANSWER current,
    historical, interval admitted; ambiguous abstains; execution/belief rejected.
    Other purposes rejected before analysis; all 18 combinations are closed.
12. Structured claims plus full evidence closure are one budget unit, deterministic
    IDs, no partial categorical answer or lexical truth fallback.
13. Exact charged UTF8 fields include text, record/domain/source kind/source IDs/
    provenance; count/item/byte caps explicit. Omission IDs have their independent
    cap and full authorized count with truncation indication.
14. Real factory/filesystem/Hermes carry same authority and ingress to canonical
    owner. Old construction/prefetch remain compatible, no automatic opt-in.
15. No new persisted indexes/events, mutation, cross-store execution checkpoint,
    learned-control promotion or live acceptance. Current-state doc and usage
    example show opt-in and limits without modifying frozen approved source.
16. Tests independently assert intended failures, root reachability, snapshot
    purity, byte accounting, temporal matrix, typed outages and identity governance.
    Workflow/timing ownership and exact source identity accompany local evidence.

Parent M5 scheduling has no new runtime contract in this slice. Its external
