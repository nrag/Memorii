# Observation Registry Source Roles

This construction candidate contains the grammar, seven roles for each of 179
schemas, the registry role, decoder-source manifest and publication manifest.
It is not an activated registry or deployment authority. Complete independent
vectors, source-closure review and protected publication pins must verify before
runtime composition can expose it.

Every JSON role is canonical UTF-8 with no terminal newline. The production
compiler consumes these exact raw bytes, never Pydantic annotations or the
offline drafting tool. Acceptance witness schemas are excluded.
